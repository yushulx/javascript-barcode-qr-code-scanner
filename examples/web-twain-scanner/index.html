No physical scanner? Get a virtual scanner

Install a virtual scanner to scan sample images through the same scanning workflow. Each package ships 11 sample images, so every scan returns a different picture — and a document-feeder scan returns all of them as one multi-page document.

Windows installation guide

macOS / Linux installers and source code

Prebuilt packages are attached to the release — no build tools required:

macOS package (.pkg) · Linux DEB (x64)

macOS: run curl -fsSL https://raw.githubusercontent.com/yushulx/virtual-scanner/main/macos/Scripts/install.sh | bash (one-line installer, always the latest release), then open Image Capture — or install the .pkg manually. Linux: run sudo apt install ./sane-custom-scanner_1.0.7_amd64.deb, then run scanimage -L.
