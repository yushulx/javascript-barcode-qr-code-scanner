This scanner reads barcodes, not OCR. Dynamsoft decodes the VIN from a barcode symbol — Code 39, Code 128, QR Code or Data Matrix. The stamped, engraved or plain printed VIN characters themselves are not recognized: if a VIN label carries no barcode, a barcode scanner has nothing to read.
