    How to read this report

    This is a software-based scanability diagnostic, not an ISO-certified barcode verifier or a print-quality grade. Decode success applies to this image and this reader's default settings; it does not guarantee other scanners will read it.

    Manual selections are analyzed directly from image pixels, even if the reader fails. Contrast measures grayscale differences; broad brightness transitions can suggest soft edges, while dim lighter pixels can suggest poor lighting. These are possible contributing factors, not proof of why decoding failed. A rectangular box does not establish barcode format, module size, orientation or perspective. Include the complete symbol and a small clear margin; avoid large areas of unrelated background.

    For detected symbols, the SDK supplies location, module size and rotation. Selection-border and quiet-zone estimates are separate: a manual box checks its inner border, while a localized symbol checks surrounding pixels. Neither verifies format-specific quiet-zone compliance. White paper can resemble glare, and valid patterns can resemble damage. Unknown values are never counted as passes.

    The optional selected-area decode test uses an unmodified crop at original resolution. If it succeeds after a full-image failure, restricting the area changed the result; this does not prove the original cause. Image evidence remains available when crop decoding fails or the SDK cannot activate.

    Images are processed in your browser. The SDK downloads its engine and contacts Dynamsoft for license activation. The hosted demo uses the CodePool domain license; local and self-hosted previews use the SDK trial license.
