THE RULE BEHIND THE GAME

Deduplicate a package presentation, not a GTIN.

A barcode tells the checkout what product this is. It does not tell it which physical package just crossed the scanner. Matching carrier reads inside one presentation become one cart commit; a second package is a new presentation.

01

Read the carriers

EAN-13 supplies a GTIN. The QR carries a GS1 Digital Link URI with AI (01), lot and expiry. Both symbols in the game are real, rendered images.

02

Normalize and compare

The linear value becomes a canonical GTIN-14 and its check digit is verified. Two valid but different GTINs are a conflict, not a race for the scanner to win.

03

Commit once per pass

Same GTIN, same package: one unit. Same GTIN, second physical package: another unit. A permanent GTIN cache would block a legitimate second purchase.

What is dual marking?

A package carries both an established EAN/UPC symbol and a 2D carrier, often to add richer product data during migration. When both represent one item, the POS processes one set of desired data rather than charging twice.

Does Ambition 2027 make EAN-13 invalid?

No. It is an industry POS-readiness goal for defined 2D carriers, not a claim that 1D barcodes stop working in 2027. Existing linear checkout remains part of this lab.

Why does level 4 need two scans?

Each click creates a new physical package presentation. Clicking Repeat Pass explicitly reuses the same presentation and must not add another unit.

What does SDK mode prove?

It shows whether Dynamsoft decoded the generated or uploaded image and exposes the genuine returned text. It does not establish camera grouping, scanner hardware behavior or GS1 certification.
